## 📌 Project Overview

A3G-PMO is an AI-powered Agile Governance Platform that analyzes GitHub repositories in real time and provides governance insights using Machine Learning and Explainable AI.

The platform assists Project Managers and PMOs in identifying repository risks, compliance issues, and overall project health.

---

## ✨ Features

- Live GitHub Repository Analysis
- Machine Learning Risk Prediction
- Explainable AI (SHAP)
- Governance Risk Engine
- Compliance Analysis
- Project Health Assessment
- AI Governance Assistant
- Repository Trend Analytics
- Historical Analysis Database
- PDF Governance Report
- Interactive Streamlit Dashboard

---

## 🧠 Machine Learning

Algorithms evaluated:

- Decision Tree

- Gradient Boosting (Selected Model)

Performance:

- Accuracy ≈ 97%
- Cross Validation
- Model Comparison

## 🔍 Explainable AI

The platform explains every prediction using SHAP values.

Features influencing prediction include:

- Open Issues
- Pull Requests
- Contributors
- Recent Commits
- Repository Age
- Stars
- Security Issues
